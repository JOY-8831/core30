# CORE / 30 — 30 天核心訓練

手機優先、繁體中文的靜態網站，直接使用 HTML、CSS、JavaScript，無需建置或後端。

## 使用

打開 `index.html` 可直接查看；建議透過網站網址使用，讓 localStorage 在固定網域正常保存。首頁選擇開始日期，點 Day 1–30 查看課表，再按 Start Workout。

- 預設下一個週一開始（當天是週一則從當天開始）；可自行選日期，真正的星期六、日一定使用固定穩定課表。
- 每日訓練可自由開啟，不鎖天數；錯過一天不必補兩份。
- Pause 暫停、Resume 繼續，返回課表或頁面進入背景自動暫停。重新整理可續練。
- Next 跳過目前段落。若跳過主要動作或啟動，結束時需自行確認完成；未跳過的訓練倒數完會自動打勾。
- 可手動標記完成或取消勾選。改開始日期會先確認，再清除本課表紀錄。
- localStorage key 為 `core30-v1`。記錄只存在目前瀏覽器及網域，清除瀏覽資料即會失去；不跨裝置同步。儲存不可用時顯示提示並保留本次頁面的操作。
- 網頁在背景或螢幕鎖定時暫停；練習時保持畫面開啟。每段剩 10 秒時會說「剩下十秒」，數字變紅並脈動；可在計時頁關閉語音。語音由瀏覽器與裝置的中文語音提供，實際播放依裝置支援；未支援時保留視覺提示。暫停會停止播報，同一段不重複提醒。計時頁固定在單一畫面，手機橫向改為左右排列；開啟減少動態效果時只變紅、不脈動。

## GitHub Pages 部署

1. 解壓縮 `core30-github-pages.zip`。
2. 把解壓縮後的內容上傳到 GitHub repository 的根目錄，確認 `index.html` 在根目錄，而非再包一層資料夾。
3. 在 repository 的 **Settings → Pages → Build and deployment**，Source 選 **Deploy from a branch**，Branch 選放置檔案的分支（通常是 `main`），資料夾選 **/ (root)**，按 Save。
4. 等待 GitHub Pages 顯示網址，以手機開啟。所有網站資源均使用相對路徑，適用於 `https://使用者.github.io/儲存庫名稱/`。

這份交付是可部署的網站檔案，尚未替你建立 GitHub repository 或公開發布。

## 每週一：影片五動作

來源：[使用者提供的 YouTube 影片](https://www.youtube.com/watch?v=wMCFIixwgac)。本次無法取得影片內容；動作名稱與原始次數依使用者提供的截圖，未自行推定作者或影片標題。

- 蠶蛹式捲腹：原圖 10–15 次。
- 俄羅斯轉體變式：原圖每邊 10 次。
- 平板支撐起身：原圖 10–15 次。
- 反向捲腹：原圖 15–20 次。
- 跪姿真空腹：原圖 5 組，每組 20 秒。

本站計時改編：30 秒啟動 → 前四個動態動作一輪（各 45 / 50 / 55 / 60 秒，依四階段增加，每個後休息 20 秒）→ 真空腹 5 組（20 秒練習 + 10 秒放鬆）。總時間依階段為 7:20 / 7:40 / 8:00 / 8:20。完成參考次數可在剩餘秒數休息，不強求在時間內追完次數。簡易版與呼吸提示為本站調整：真空腹採可自然呼吸的輕收腹，20 秒不是閉氣時間。

實際日期為週一才套用；改開始日期後也會正確移動。預設週一開始時是 Day 1、8、15、22、29。已完成紀錄保留；舊版週一未完成計時會從新版課表重新開始，避免段落錯位。

所有時間都含 30 秒呼吸啟動。每個主要動作之後皆有休息，最後一段稱為放鬆；週末再加 10 秒放鬆，總長恰為 6 分鐘。左右交替的動作要平均分配兩側；週末側棒式每側共 60 秒。

平日每次涵蓋軀幹屈曲、骨盆後傾或抬腿控制、旋轉或抗旋轉、抗伸展。以動作品質、短暫停頓及活動幅度漸進，不要求每天力竭。Day 30 回顧控制品質，不做最大次數測試。週末是低變化的穩定練習，不等於完全休息；需要恢復時可跳過或降階。

採用使用者上傳的 `athleanx-22-days-to-a-flat-stomach.pdf` 第 2–3、5–7 頁的深層核心啟動及 static → dynamic → integration 概念，重新編排，沒有複製 22 天內容。為符合「平日皆有動態動作」，第一階段在穩定軀幹下做低難度、小幅度動態練習。截圖的黑底列表、红色秒數及右側影片位置作為介面參考。PDF 與截圖未隨網站重新散布。

動作控制的補充依據：[ACE — Spinal Stability: To Brace or Not to Brace?](https://www.acefitness.org/continuing-education/certified/november-2018/7120/spinal-stability-to-brace-or-not-to-brace/)。此課表是原型中的一般運動安排，不是驗證過的 30 天治療方案，也不承諾局部減脂。

## 放入自己拍攝的影片

`plan.js` 裡的 `EXERCISES` 有每個動作的固定 ID。影片放進 `videos/`，建議使用 H.264 編碼的 MP4（手機相容性較好）。

例如 `videos/curl.mp4` 放好後，在 `plan.js` 的 `Object.entries(EXERCISES).forEach(...)` 那一行下方加入：

```js
EXERCISES.curl.video = 'videos/curl.mp4';
EXERCISES.breath.video = 'videos/breath.mp4';
```

其他動作依 `videos/README.md` 的表格設定。每個動作只設定一次，所有天數、輪數和計時頁自動共用。預設是明確標示「影片待拍」的區塊，不會請求不存在的影片。影片為手動播放，播放影片與訓練計時分開控制。

## 六階段排序

平日每輪保留原本動作數、秒數與休息，依 1 抬腿控制 → 2 由下往上 → 3 腹斜肌 → 4 中段屈曲 → 5 由上往下旋轉 → 6 由上往下屈曲排序；未安排階段跳過，不增加動作。啟動、輪末穩定補充、真空腹收尾另列，不硬套分類。週末固定穩定課表不變。序列採 ATHLEAN-X 作者編排概念，本站為既有動作／簡易版本作功能對應，並非唯一標準或原片順序。

圖中階段跟隨選中動作；計時器使用同一份排序。肌群拆分腹內外斜肌，深層以透視示意；支撐動作標示前鋸肌協助肩胛穩定，不代表其為腹肌或主要訓練目標。舊版平日未完成計時重設，已完成紀錄保留。
